## 2. 考试集（13 张图，1 正 + 12 负）

正样本 = 含真实河道漂浮垃圾；负样本 = 室内杂乱 / 暗光场景（不应告警）。

| 项 | 结果 |
|---|---|
| 正样本命中 | **3 / 3**（置信度 0.90 / 0.79 / 0.78） |
| 漏检 | **0** |
| 负样本误报 | **6 / 12 张**，共 11 个框 |
| 误报框置信度区间 | 0.29 ~ 0.65（全部 < 0.65） |
| 框级 Precision | 3 / 14 = **21.4%** |
| 框级 Recall | 3 / 3 = **100%** |
| 告警漏报率 | **0%** |
| 告警误报率 | **50%** |

### 结论

- 对**真实垃圾目标**检出可靠，不漏报 —— 这是告警系统的底线要求。
- 短板是**室内杂乱/暗光**场景下的低置信误报（全部 < 0.65）。
- 阈值实验：`OBJ_THRESH` 0.25 → 0.5 可消掉 11 个误报中的 7 个，但会牺牲部分召回。v1 保持 0.25 未改，属于已知的下一步优化项。

> 说明：考核集本身很小（13 张），上面数字只能反映"链路可用性"和"误报倾向"，不能当泛化性能结论。

## 5. 复现时如何自己测一遍

```bash
# 帧率：看服务日志
journalctl -u rtsp-stream -n 50 | grep -i fps

# 温度
python3 scripts/thermal_monitor.py --interval 1    # 直接看 OLED

# 告警链路
python3 scripts/listen_alert.py

# 模型单图精度（把自己的图放 images/）
bash scripts/infer.sh <你的图>.jpg
```

复现结果与上表同量级（帧率 ±2 fps、温度 ±5℃）即视为一致。
